## 🏛️ Platform Architecture & Overview

CoBuild is a high-fidelity, interactive PropTech platform designed for the Egyptian real estate market, introducing democratic co-development, construction transparency, and milestone-based escrow payments.

### Tech Stack:
- **Backend**: Zero-dependency Python HTTP REST server (`backend/app.py`) listening on `$PORT` (default 8080).
- **Database**: SQLite relational database (`backend/cobuild.db`) with 11 tables.
- **Frontend**: Clean semantic HTML5, Vanilla JavaScript, Tailwind CSS (CDN), Lucide Icons, Cairo & Tajawal Arabic typography, and Material Symbols.
- **Micro-animations**: Custom CSS keyframes (`fadeInUp`, `pulseGlow`, `liveBeacon`, `springyBookmark`).
- **Zero-downtime Probe**: `/healthz` endpoint returning `{"status": "healthy", ...}`.

## 🗄️ Database Models (SQLite)

Tables in `backend/cobuild.db`:
1. `projects`: Project details, completion rates, location, and contractor info.
2. `units`: Individual units (e.g. Unit 302, 401, 501, Penthouse), cost vs market price, floor plans, reservation status.
3. `daily_logs`: Day-by-day site inspection records, workforce headcount, slump tests, photos.
4. `buyer_reservations`: Buyer co-ownership records, payment schedules, escrow accounts.
5. `syndicate_votes`: Democratic voting on project finishings, amenities, and vendor selection.
6. `reports`: Monthly executive progress reports.
7. `milestones`: Key construction milestones & timelines.
8. `floor_inspections`: BIM structural inspections with concrete strength (MPa).
9. `budget_invoices`: Itemized financial ledgers and vendor payouts.
10. `rfis`: Engineering Requests for Information and approvals.
11. `iot_telemetry`: IoT sensor streams (curing temperature, crane tilt, noise, AQI).
